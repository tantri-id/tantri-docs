## Development

<Callout title="Prerequisite">
  Please install <b>Yarn</b> and <b>Node.js 18+</b> before proceeding with the
  installation.
</Callout>

Follow these steps to run this project locally.

<Steps>
<Step>
Clone the repository
```bash
git clone git@github.com:tantri-id/tantri-app-react-native.git
```
</Step>

<Step>
Navigate to the project directory

```bash
cd tantri-app-react-native
```

</Step>

<Step>
Install dependencies

```bash
yarn install
```

</Step>

<Step>
Setup environment variables

Copy `.env.example` to `.env` and fill `GOOGLE_MAPS_API_KEY`, `ANDROID_PACKAGE_NAME`, `ANDROID_SHA1_FINGERPRINT`.

```bash
cp .env.example .env
```

</Step>

<Step>
(iOS only) Install Ruby gems and CocoaPods

```bash
bundle install
bundle exec pod install
```

</Step>

<Step>
Start the Metro bundler

```bash
yarn start
```

Use `yarn start --reset-cache` after dependency or native changes.

</Step>

<Step>Open your Android Emulator or iOS Simulator</Step>

<Step>
Start on Android Emulator or iOS Simulator

```bash
yarn android              # for android
yarn android:optimized    # android in debugOptimized mode
yarn ios                  # for ios
```

</Step>

<Step>Open your IDE and Start Development!</Step>

</Steps>

<Callout title="Note">
  Native dependency changes require a full rebuild (`yarn android` /
  `yarn ios`), not just a Metro reload. `postinstall` runs `patch-package` —
  patches live in `patches/`, never hand-edit `node_modules`.
</Callout>

## Linting, Type Check & Testing

```bash
yarn lint              # ESLint
yarn tsc --noEmit       # TypeScript check
yarn test               # Jest unit tests
yarn test path/to/file  # Single test file
maestro test tests/main-test.yaml  # E2E (requires maestro CLI)
```

Run lint and type check before pushing.

## Production

Building app apk or aab for android

### Cleaning Gradle Build

```bash
cd android/
./gradlew clean
```

### Building APK Files

```bash
cd android/
./gradlew assembleRelease
```

### Building AAB File

```bash
cd android/
./gradlew bundleRelease
```
