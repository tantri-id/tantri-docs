---

Tantri POS is mobile application used to manage cafe/restaurant transactions — orders, payments, products, table management, reservations, shift, reports, and printing. Built with React Native 0.83 (New Architecture) and TypeScript, package manager **Yarn**. Primary platform is Android (BLE thermal printers, external customer displays); iOS supported too.

Before you start, set up React Native environment. Visit [React Native Setup Environment](https://reactnative.dev/docs/set-up-your-environment) page.
