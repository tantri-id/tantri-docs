# Merchant > Audit Aktif

Halaman **Merchant Audit Aktif** digunakan untuk menampilkan daftar merchant yang sedang dalam status audit namun tetap tercatat di sistem. Dari sini admin dapat mengaktifkan kembali merchant jika diperlukan.

---

## Fitur Pencarian

- **Cari nama toko** → Memudahkan pencarian merchant berdasarkan nama toko.

---

## Kolom Data pada Tabel

Tabel **Merchant Audit Aktif** berisi informasi berikut:

1. **Nama Toko**

   - Nama toko atau outlet merchant.

2. **Status**

   - Status merchant saat ini.
     - Pada halaman ini umumnya ditandai `Passive` (Oranye) untuk menunjukkan merchant tidak aktif namun masih dalam audit.

3. **Alamat**

   - Alamat lengkap lokasi toko.

4. **Nama Office**

   - Nama kantor induk/merchant pemilik toko.

5. **Nominal Credit**

   - Jumlah kredit yang tersisa pada merchant (Rp).

6. **Aksi**
   - Tombol **Aktifkan Merchant** (Merah dengan ikon jam) untuk mengubah status merchant dari `Passive` menjadi `Aktif`.

---

## Fungsi Tombol "Aktifkan Merchant"

- Mengubah status merchant dari `Passive` menjadi `Aktif`.
- Mengembalikan merchant ke daftar **Merchant Aktif** sehingga dapat kembali beroperasi.
