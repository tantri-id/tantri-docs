# Pengajuan > Cabang

Halaman **Pengajuan Cabang** digunakan untuk memantau dan mengelola pengajuan pembuatan cabang baru dari merchant. Admin dapat melihat informasi detail pemilik, melakukan verifikasi, atau menolak pengajuan.

---

## Fitur Pencarian

- **Cari nama toko** → Memudahkan pencarian pengajuan cabang berdasarkan nama toko.

---

## Kolom Data pada Tabel

Tabel **Pengajuan Cabang** menampilkan informasi berikut:

1. **Nama Toko**

   - Nama toko atau cabang yang diajukan.

2. **Nama Pemilik**

   - Nama pemilik merchant atau pengelola cabang.

3. **Email**

   - Alamat email pemilik merchant.

4. **Nomor HP**

   - Nomor telepon pemilik merchant.

5. **Verifikasi**
   - Status verifikasi cabang:
     - 🟢 `Accepted` → Pengajuan telah disetujui.
     - 🔴 `Accept` → Pengajuan belum disetujui dan menunggu konfirmasi admin.

---

## Fungsi Status Verifikasi

- **Accepted** → Cabang baru telah diverifikasi dan ditambahkan ke sistem.
- **Accept** → Menandakan admin perlu melakukan konfirmasi untuk menyetujui cabang.
