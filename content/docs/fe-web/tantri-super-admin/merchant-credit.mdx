# Merchant > Credit

Halaman **Credit** digunakan untuk memantau dan mengelola seluruh riwayat penambahan kredit merchant. Admin dapat mencari data, memfilter berdasarkan tanggal, serta mengunduh laporan dalam format Excel.

---

## Fitur Pencarian & Filter

- **Cari nama toko** → Memudahkan pencarian data berdasarkan nama toko/cafe.
- **Filter Tanggal** → Memilih periode tanggal awal dan akhir untuk menampilkan data kredit sesuai rentang waktu yang diinginkan.
- **Download Excel** → Mengunduh laporan data kredit sesuai hasil filter.

---

## Kolom Data pada Tabel

Tabel **Credit** menampilkan informasi berikut:

1. **Tanggal Credit**

   - Tanggal penambahan kredit dilakukan.

2. **Nama Cafe**

   - Nama toko/cafe penerima kredit.

3. **Nama Office**

   - Nama kantor induk/merchant yang menaungi toko tersebut.

4. **Input By**

   - Nama admin atau user yang melakukan input kredit.

5. **Tambahan Credit**

   - Jumlah kredit yang ditambahkan (Rp).

6. **Tipe Credit**

   - Jenis kredit yang diberikan, contoh:
     - `Topup`
     - `Bonus`

7. **Catatan**

   - Informasi tambahan atau alasan pemberian kredit.

8. **Attachment**

   - Jumlah lampiran bukti atau dokumen terkait.
   - Ikon 📎 dapat diklik untuk melihat atau mengubah lampiran.

9. **Aksi**
   - Menu tindakan untuk mengelola catatan dan lampiran.

---

## Menu Aksi (⋮)

Klik tombol **tiga titik (⋮)** pada kolom **Aksi** untuk membuka opsi:

- **Ganti Lampiran** → Mengubah atau menambahkan dokumen/lampiran bukti kredit.
- **Ganti Catatan** → Mengubah catatan pada data kredit.
