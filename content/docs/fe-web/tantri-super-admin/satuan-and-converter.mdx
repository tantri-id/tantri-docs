# Satuan & Konverter

Modul **Satuan** dan **Konverter** digunakan untuk mengelola daftar satuan ukuran yang dipakai di sistem, serta mengatur konversi antar satuan.

---

## Halaman Satuan

Halaman **Satuan** digunakan untuk membuat, melihat, dan mengedit daftar satuan yang digunakan pada produk atau transaksi.

### Fitur Utama

- **Cari nama satuan** → Mencari satuan berdasarkan nama.
- **Tambah Satuan** → Membuka formulir untuk menambahkan satuan baru.

### Kolom Data

1. **Nama Satuan** → Nama satuan yang digunakan (misalnya gram, liter, pcs).
2. **Tipe** → Kategori satuan:
   - `WEIGHT` → Berat (gram, kilogram, miligram, dll)
   - `VOLUME` → Volume (liter, mililiter, dll)
   - `OTHER` → Lainnya (pcs, setengah pcs, dll)
3. **Aksi** → Ikon ✏️ untuk mengedit data satuan.

---

## Halaman Konverter Satuan

Halaman **Konverter Satuan** digunakan untuk membuat aturan konversi antar satuan, sehingga sistem dapat otomatis menghitung perubahan dari satu jenis satuan ke satuan lain.

### Fitur Utama

- **Cari nama satuan** → Mencari data konversi berdasarkan nama satuan.
- **Tambah Konverter** → Membuka formulir untuk menambahkan aturan konversi baru.

### Kolom Data

1. **Dari Satuan** → Satuan asal yang akan dikonversi.
2. **Ke Satuan** → Satuan tujuan hasil konversi.
3. **Pengali** → Nilai perkalian yang digunakan untuk konversi (misalnya: 1 kilogram = 1000 gram → pengali = 1000).
