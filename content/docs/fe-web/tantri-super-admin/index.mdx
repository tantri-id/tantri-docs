This is web application for Tantri Super Admin which is used for manage feature and configuration by Super Admin. This web app created using Nextjs with programming language typescripts.

So before you start, make sure you have already setup the environment for developing NodeJS Application. You can use any package manger like <b>npm, yarn, pnpm, or bun</b> to install and run this app.

## Techstack :

- Nextjs 14
- Typescripts
- Ant design 5
- Tailwind css
- Tanstack React Query
- react-hook-form
- zod
