# Modul Panduan

Modul **Panduan** digunakan untuk mengelola artikel dan video tutorial yang membantu pengguna memahami fitur-fitur sistem. Admin dapat membuat, mengedit, menghapus, dan mengelompokkan panduan berdasarkan kategori dan sub kategori.

---

## Daftar Panduan

Halaman **Daftar Panduan** berisi semua artikel dan video panduan yang telah dibuat.

### Fitur Utama

- **Cari Panduan** → Mencari panduan berdasarkan judul.
- **Buat Artikel** → Membuat panduan baru (artikel atau video).
- **Edit Artikel** → Mengubah konten panduan yang sudah ada.
- **Delete Artikel** → Menghapus panduan dari sistem.

### Kolom Data

1. **Judul Artikel** → Judul panduan/tutorial.
2. **Tipe Panduan** → Jenis panduan (`Video` atau `Artikel`).
3. **Kategori** → Kategori panduan (misalnya: _Kasir TANTRI_, _Order Management_).
4. **Sub Kategori** → Sub kategori detail (misalnya: _POS Digital_, _Katalog Menu_).
5. **Status** → Status publikasi panduan (`Published`).
6. **Edit By** → Nama admin terakhir yang mengedit panduan.
7. **Published** → Tanggal dan waktu panduan dipublikasikan.
8. **Aksi** →
   - Edit Artikel
   - Delete Artikel

---

## Kategori

Halaman **Kategori Artikel** digunakan untuk mengelompokkan panduan ke dalam kategori besar.

### Fitur Utama

- **Cari Kategori** → Mencari kategori berdasarkan nama.
- **Tambah Kategori** → Membuat kategori baru.
- **Edit Kategori** → Mengubah nama atau slug kategori.
- **Delete Kategori** → Menghapus kategori.

### Kolom Data

1. **Name** → Nama kategori (misalnya: _Order Management_, _Kasir TANTRI_).
2. **Slug** → URL slug kategori (otomatis dihasilkan berdasarkan nama).
3. **Aksi** →
   - Edit Kategori
   - Delete Kategori

---

## Sub Kategori

Halaman **Sub Kategori Artikel** digunakan untuk membuat pengelompokan lebih spesifik di dalam kategori.

### Fitur Utama

- **Cari Sub Kategori** → Mencari sub kategori berdasarkan nama.
- **Tambah Sub Kategori** → Membuat sub kategori baru dan menentukan kategori induknya.
- **Edit Sub Kategori** → Mengubah nama sub kategori atau kategori induknya.
- **Delete Sub Kategori** → Menghapus sub kategori.

### Kolom Data

1. **Name** → Nama sub kategori (misalnya: _POS Digital_, _Printer Bluetooth_).
2. **Name Kategori** → Kategori induk dari sub kategori tersebut.
3. **Aksi** →
   - Edit Sub Kategori
   - Delete Sub Kategori
