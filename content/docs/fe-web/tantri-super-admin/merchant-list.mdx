# List Toko (Merchant)

Halaman **List Toko** digunakan untuk mengelola seluruh toko yang terdaftar di sistem. Admin dapat melihat detail, mengubah status, serta melakukan berbagai tindakan manajemen toko.

---

## Pencarian Toko

🔍 **Cari nama toko** — Input pencarian di bagian atas memungkinkan admin mencari toko berdasarkan nama secara cepat.

---

## Kolom Data Toko

Tabel utama berisi beberapa kolom informasi:

1. **Nama Toko**

   - Nama toko yang terdaftar.
   - Dapat di-_click_ untuk detail (melalui menu aksi).

2. **Status**

   - Menunjukkan status operasional toko.
     - `Preparation` (Ungu)
     - `Tidak Aktif` (Merah)
     - `Dummy` (Biru)
     - `Aktif` (Hijau)
     - `Passive` (Oranye)

3. **Alamat**

   - Alamat lengkap lokasi toko.

4. **Nama Office**

   - Nama kantor/merchant yang menaungi toko tersebut.

5. **Nominal Credit**

   - Jumlah kredit yang dimiliki toko (Rp).

6. **Diskon**

   - Menampilkan informasi diskon aktif jika ada.

7. **Jenis Penagihan**

   - `Dinamis` atau jenis lain sesuai pengaturan merchant.

8. **Status Pengajuan**

   - Menunjukkan status jika toko sedang dalam proses pengajuan tertentu.

9. **Assignment By**

   - Menampilkan siapa yang memberikan penugasan toko.

10. **City Ledger**

    - Status _City Ledger_ (Aktif / Tidak Aktif).

11. **Compliment**

    - Status _Compliment_ (Aktif / Tidak Aktif).

12. **Schedule Active**

    - Jadwal aktif toko.

13. **Aksi**
    - Menu tindakan untuk mengelola toko.

---

## Menu Aksi (Tombol ⋮)

Klik tombol **tiga titik** (`⋮`) pada kolom **Aksi** untuk membuka daftar opsi:

1.  **Lihat Detail** — Menampilkan informasi detail toko.
2.  **Ubah Status** — Mengubah status operasional toko.
3.  **Ubah Penagihan** — Mengubah jenis penagihan toko.
4.  **Input Schedule Active** — Menambahkan atau mengubah jadwal aktif toko.
5.  **Input Assignment** — Menentukan atau mengubah penugasan admin terhadap toko.
6.  **Input Credit** — Menambahkan saldo kredit toko.
7.  **Aktifkan City Ledger** — Mengaktifkan fitur _City Ledger_ untuk toko.
8.  **Aktifkan Compliment** — Mengaktifkan fitur _Compliment_ untuk toko.
9.  **Tambah Diskon** — Menambahkan diskon untuk toko.
