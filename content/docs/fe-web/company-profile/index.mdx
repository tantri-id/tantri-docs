This is web application for Tantri Company Profile which is used for show product profile information and promotion. This web app created using Nextjs with programming language typescripts.

So before you start, make sure you have already setup the environment for developing NodeJS Application. You can use any package manger like <b>npm, yarn, pnpm, or bun</b> to install and run this app.

## Techstack :

- Nextjs 13
- Typescripts
- Shadcn UI
- Tailwind css
- Tanstack React Query
- GraphQL
